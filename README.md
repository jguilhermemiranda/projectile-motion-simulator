# Motion Simulator

Simulação do movimento de corpos desenvolvida em Python durante uma aula de Física.

Projectile motion simulation developed in Python during a Physics class.

---

Este projeto foi desenvolvido durante uma aula de **Física**, como uma forma de aplicar conceitos de **movimento de projéteis** utilizando programação.

O programa simula o movimento de corpos lançados em diferentes ângulos e gera um gráfico com suas trajetórias.

### Tecnologias

- Python
- NumPy
- Matplotlib

### Conceitos utilizados

- Movimento de projéteis
- Velocidade inicial
- Gravidade
- Ângulo de lançamento
- Trajetória parabólica

---

This project was developed during a **Physics class** as a way to apply **projectile motion** concepts using programming.

The program simulates the motion of bodies launched at different angles and generates a graph showing their trajectories.

### Technologies

- Python
- NumPy
- Matplotlib

### Concepts

- Projectile motion
- Initial velocity
- Gravity
- Launch angle
- Parabolic trajectory
